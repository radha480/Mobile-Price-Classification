# Mobile-Price-Classification
#Overview:
The Mobile Price Classification project aims to predict the price range of a mobile phone based on its specifications. Using machine learning algorithms like K-Nearest Neighbors (KNN) and Gaussian Naive Bayes (GaussianNB), the model helps identify whether a mobile phone falls into a low, medium, high, or very high price category.

This project demonstrates key concepts in data preprocessing, feature engineering, model training, and evaluation.

🧩 Model Training
The project uses the following ML models:
K-Nearest Neighbors (KNN)
Gaussian Naive Bayes (GaussianNB)

Steps:
Import libraries and dataset
Data preprocessing and feature selection
Train–test split
Model training using KNN and GaussianNB

Model evaluation using:
Accuracy Score
Confusion Matrix
Classification Report

Python 🐍
